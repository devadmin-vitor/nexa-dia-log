# Frontend — Claude Commerce AI

Dashboard Next.js 16 (App Router, Cache Components) + TypeScript + Tailwind 4.
Instruções de execução no README principal: `../README.md`.

- `src/lib/api.ts` — cliente do backend (somente servidor, `server-only`).
- `src/lib/actions.ts` — Server Actions (mutações); o token nunca chega ao navegador.
- `src/proxy.ts` — Basic Auth opcional do dashboard.
